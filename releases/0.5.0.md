## What's new since 0.4.0

- Added daily schedules and battery-percentage triggers for monitor controls, with 12-/24-hour time display.
- Added System colors (including Breeze palettes), Light, Dark, and AMOLED Black themes.
- Added Light/Dark Green, Light/Dark Blue, Purple, Red, Orange, Grey, Brown, and Yellow themes, with instant switching and saved preferences.
- Modernized the Qt Quick interface, settings pages, monitor cards, and slider interactions.
- Added a default-enabled option to hide the window when clicking its tray icon.
- Updated translations across all 12 supported languages.

## Downloads

- `brightless-v0.5.0-windows-x64.zip` — portable Windows 10/11 x64 build with Qt runtime; unsigned, so SmartScreen may warn.
- `brightless-v0.5.0-linux-x64.zip` — dynamically linked Linux x86-64 build from Fedora 44; requires compatible Qt/KDE/DDC runtime libraries.
- `brightless-0.5.0-x86_64.AppImage` — Linux x86-64 AppImage, built on Debian 13 (glibc 2.41 or newer, with standard desktop font/graphics libraries).
- `brightless-0.5.0-x86_64.flatpak` — Linux x86-64 Flatpak bundle using the KDE 6.11 runtime; install the Flathub remote first.
- `brightless-0.5.0-1-x86_64.pkg.tar.zst` — Arch Linux package.
- `brightless-0.5.0-1.fc44.x86_64.rpm` — Fedora 44 package.
- `brightless_0.5.0-1_amd64.deb` — Debian 13 package; install with `sudo apt install ./brightless_0.5.0-1_amd64.deb` to resolve dependencies.
- `SHA256SUMS` — checksums for all seven downloads.

Linux packages were built and checked in Docker. Windows and Linux CI passed, including installed-application smoke tests. Arch packaging checks exclude the SDR test because its KScreen Fake test backend fails; Debian and Fedora CI cover that test.

Monitor DDC/CI support and Linux I2C permissions are still required. The Flatpak needs device access for DDC/CI. SDR brightness on HDR displays is supported on KDE Plasma Wayland; Windows HDR SDR-white-level controls are not included. Packages are unsigned, and real-hardware behavior was not tested for this release.
