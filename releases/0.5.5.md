## What's new since 0.5.0

- Added global shortcut assignment directly in **Settings → System** on Plasma and Windows, with rounded shortcut cards and saved bindings retained when shortcuts are disabled.
- Added shortcut conflict checks and startup comparison with Plasma settings; conflicting or mismatched bindings are reported without silently overwriting them. Hardened Windows hotkey message handling against crashes.
- Added native Plasma Night Light scheduling and Windows desktop color filtering, with sunset/sunrise, custom times, morning/night temperatures, and smooth transitions.
- Added an offline world map for manual Night Light location and optional, explicit IP-based location detection.
- Added Windows HDR SDR white-level brightness controls, matching Windows' 80–480-nit slider range.
- Improved schedule help, updated shortcut translations across all 12 supported languages, and moved build and packaging instructions to `BUILD.md`.

## Downloads

- `brightless-v0.5.5-windows-x64.zip` — portable Windows 10/11 x64 build with Qt runtime; unsigned, so SmartScreen may warn.
- `brightless-v0.5.5-linux-x64.zip` — dynamically linked Linux x86-64 build from Fedora 44; requires compatible Qt/KDE/DDC runtime libraries.
- `brightless-0.5.5-x86_64.AppImage` — Linux x86-64 AppImage, built on Debian 13 (glibc 2.41 or newer, with standard desktop font/graphics libraries).
- `brightless-0.5.5-x86_64.flatpak` — Linux x86-64 Flatpak bundle using the KDE 6.11 runtime; install the Flathub remote first.
- `brightless-0.5.5-1-x86_64.pkg.tar.zst` — Arch Linux package.
- `brightless-0.5.5-1.fc44.x86_64.rpm` — Fedora 44 package.
- `brightless_0.5.5-1_amd64.deb` — Debian 13 package; install with `sudo apt install ./brightless_0.5.5-1_amd64.deb` to resolve dependencies.
- `SHA256SUMS` — checksums for all seven downloads.

The release workflow runs Windows/Linux tests and package installation/smoke checks, then generates SHA-256 checksums before publication.

Monitor DDC/CI support and Linux I2C permissions are still required. The Flatpak needs device access for DDC/CI; native Plasma Night Light is unavailable in its sandbox. Windows SDR white-level control uses an undocumented DisplayConfig API and may be affected by Windows updates. Windows Night Light requires Brightless to remain running. Packages are unsigned, and real-hardware behavior and desktop-wide shortcut activation were not manually tested for this release.
