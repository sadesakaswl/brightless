## What's new since 0.5.5

- Holding a global shortcut on Windows now repeats the action, matching Plasma. This applies to brightness, contrast, volume, and input switching.
- Expanded regression tests on Windows and Linux for monitor disconnect and reconnect, pending DDC writes, and simultaneous launches. Added Windows battery reader tests for valid and unavailable readings.

## Downloads

- `brightless-v0.5.6-windows-x64.zip` — portable Windows 10/11 x64 build with the Qt runtime; unsigned, so SmartScreen may warn.
- `brightless-v0.5.6-linux-x64.zip` — dynamically linked Linux x86-64 build from Fedora 44; requires compatible Qt/KDE/DDC runtime libraries.
- `brightless-0.5.6-x86_64.AppImage` — Linux x86-64 AppImage, built on Debian 13 (glibc 2.41 or newer, with standard desktop font/graphics libraries).
- `brightless-0.5.6-x86_64.flatpak` — Linux x86-64 Flatpak bundle using the KDE 6.11 runtime; install the Flathub remote first.
- `brightless-0.5.6-1-x86_64.pkg.tar.zst` — Arch Linux package.
- `brightless-0.5.6-1.fc44.x86_64.rpm` — Fedora 44 package.
- `brightless_0.5.6-1_amd64.deb` — Debian 13 package; install with `sudo apt install ./brightless_0.5.6-1_amd64.deb` to resolve dependencies.
- `SHA256SUMS` — checksums for all seven downloads.

DDC/CI behavior depends on the monitor. Monitor and battery regression tests simulate hardware responses, and held shortcuts were not manually tested with a physical keyboard.
